Systemovervåkingsdashboard med Flask
Prosjektoversikt

Dette prosjektet er et enkelt systemovervåkingsdashboard utviklet i Python med Flask. Dashboardet samler inn og viser CPU- og RAM-bruk fra maskinen det kjører på.

Prosjektet er synkronisert til GitHub og kan kjøres lokalt via et virtuelt Python-miljø.

Funksjoner
Overvåker CPU-bruk i sanntid
Overvåker RAM-bruk i sanntid
Lagrer målinger lokalt i CSV-format
Viser historiske logger i en tabell
Automatisk oppdatering av verdier hvert sekund
Støtte for e-postkontakt på nettsiden
Tilgjengelig via localhost eller lokal IP-adresse
Installasjon og oppstart
1. Åpne PowerShell

Naviger til prosjektmappen:

cd sti\til\prosjektet
2. Aktiver virtuelt miljø
.\venv\Scripts\Activate.ps1
3. Installer nødvendige pakker
pip install -r requirements.txt
4. Start Flask-serveren
python app.py
5. Åpne dashboardet

Lokalt:

http://127.0.0.1:5001

Via nettverk:

http://DIN-IP-ADRESSE:5001
Hvordan bruke dashboardet

Når dashboardet åpnes:

Flask registrerer tidspunkt.
CPU-bruk leses inn.
RAM-data leses inn.
Informasjonen lagres i access_logs.csv.
Dataene vises på nettsiden.

For å opprette en ny loggpost kan brukeren klikke på knappen "Logg".

Hvordan systemet fungerer
Første sideinnlasting

Ved første innlasting:

Tidspunkt registreres
CPU-prosent registreres
RAM-data registreres
Informasjonen lagres i access_logs.csv
Historiske målinger leses inn og vises
Løpende oppdatering

Etter innlasting:

JavaScript sender forespørsler hvert sekund
Data hentes fra API-endepunktet /api/stats
Verdiene på skjermen oppdateres automatisk
Ingen nye loggposter lagres automatisk

Historikktabellen oppdateres først ved ny sideinnlasting eller ved manuell logging.
