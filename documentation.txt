Jeg har laget en enkel Flask-dashboard som logger CPU og RAM-verdier i `access_logs.csv`, og viser dem i nettleseren.

Slik går du til prosjektet og starter dashboardet:

1. Åpne PowerShell.
2. Gå til prosjektkatalogen:
   cd "c:\Users\TORD\OneDrive - Osloskolen\2IT Kuben\programering\dashboard\Monetoring-dashboard"
3. Aktiver det virtuelle miljøet:
   .\venv\Scripts\Activate.ps1
4. Installer nødvendige pakker (hvis ikke gjort ennå):
   pip install -r requirements.txt
5. Start Flask-serveren:
   python app.py
6. Åpne nettleseren og gå til:
   http://127.0.0.1:5001/

Hvis du vil oppdatere siden og lagre en ny måling, klikker du på knappen "Oppdater" i dashboardet.

Søketermer for å finne dette:
- "python psutil cpu ram" for å finne hvordan du leser systemet CPU- og RAM-data.
- "python psutil virtual_memory" for å finne hvilken funksjon som viser RAM total, brukt og prosent.
- "python psutil cpu_percent" for å finne hvordan du måler CPU-bruk.
- "python csv writer" for å finne hvordan du lagrer logger i en CSV-fil.
